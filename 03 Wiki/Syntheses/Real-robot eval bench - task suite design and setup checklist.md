## 1. 真机评测的职责边界

真机只负责仿真测不到的东西——**三个盲区 + 一个公共品**：

1. **真实输入分布上的数值行为**：量化/压缩误差是输入依赖的，真实相机图像的纹理、噪声、光照统计与仿真图像不同 → 激活分布不同 → 仿真上数值等价不保证真实输入上等价。
2. **真实时序**：真实的延迟、抖动、GPU 争用、异步控制。仿真 Control 轴（ESAS-RoboTwin）是受控注入的近似，真机是 ground truth。
3. **真实失败分布**：滑、碰、遮挡、人为干扰的真实分布与仿真不同；Agent 框架的失败恢复能力只能在真实失败上验证。
4. **公共品——sim-real 相关性校准**：定期验证"仿真评测的结论能预测真机结论"（秩相关）。这是物理/渲染方向**可以不上真机**的合法性来源。

各方向从提交到发布的完整站位视图（含仿真层各站与判据）见 [[Embodied simulation benchmark suite for systems optimization]] §5 的端到端验收流水线；本页 R0/R1/R2 对应其中的真机站位。

**成本结构的关键事实：没有任何方向需要"每次评测微调"。** 推理优化是同 checkpoint 的不同计算实现；Agent 框架不动底层 VLA；RL 框架验收用固定 policy；物理/渲染不在真机推理链路上。微调只发生在**共享 reference 栈**的建立与更新时（一次性固定资产，见 §2），"采数据+微调"从每次评测的边际成本变为低频基建投资。

## 2. 共享真机 reference 栈（一次性基建）

所有 R1 评测都在这个冻结栈上做 A/B，不为单次评测新建：

- **checkpoint**：π0.5 在团队真机任务数据上的微调版（从 `pi05_base` 出发；已按 π0 采集的数据需确认格式后复用重训）。**每种本体配置一个多任务 checkpoint（单臂/双臂各一），全部任务数据混合微调，不逐任务微调**——逐任务 checkpoint 会使冻结/维护成本 ×N、跨任务结果不可比，且长程串联任务在定义上不能单独训（组合泛化测试即"原子训过、组合没训过"）；仿真侧先例（pi05_libero 1 个 checkpoint 40 任务、pi05_robocasa 1 个 300 任务、RoboTwin cotrain）均为多任务共训。数据采集按原子任务覆盖（已有：抓瓶/交接；补采：叠 3–4 碗；新采：抽屉、扶正瓶子；刻意不采：长程串联与一切条件），采集时自然混入多物体场景与指令措辞变体。某任务混训后达不到 40–70% 区间时，先调数据配比重训；逐任务微调是最后手段且结果须单列。冻结并记录 hash；与仿真层同基座，sim-real 秩相关校准不引入基座混杂。
- **任务集与协议**：见 §5、§6。固定初始布局集（回放预采集布局 + 半透明叠加对齐）、固定相机位、固定物体清单。
- **human baseline**：人类遥操每任务 20 次，成功率与耗时。判断任务是否饱和的唯一客观尺子。
- **难度校准**：正式评测前把 reference 校到 **40–70%** 成功率（旋钮：叠碗层数、干扰物、位置随机幅度、指令详略）。
- **失效条件**：换本体、换基座、任务资产大改 → 整栈重建（此时才再付一次微调成本）。

## 4. 三层评测结构

### R0 — 离线真实数据层（高频，可进 CI）

用已录制的真机数据，纯 GPU 作业，天然严格配对（同一批 logged 输入）：

- 量化/加速：reference 与 candidate 在同一批真实观测上推理，报动作 MSE/KL/最大偏差、逐维统计；拦截"仿真上等价、真实输入上不等价"的数值问题。
- 物理引擎：real-log action trace 双引擎重放（对应仿真层 Physics-Core 的 trace 重放，但以真实轨迹为 ground truth）。
- 渲染/3DGS：真实图像 vs 孪生场景重渲染的图像指标 + 动作分歧。
- **R0 数据集本身必须 manifest 化冻结**：episode 清单、任务覆盖、采集时段、hash——版本化扩充，否则 R0 结论跨提交不可比（真实数据也有分布漂移：物体磨损、光照季节性、相机微移）。
- **打回阈值不拍绝对数**：动作分歧容差用"噪声地板 / 良性差异带 / 坏版本带"三条参照带夹出，安全门部分（本体速度/力矩限值、norm stats P99.9）用物理依据的绝对数——校准协议见 [[Embodied sim eval - three-tier matrix by research direction]] §9.1。
- **R0 做厚是整个真机设计的第一杠杆**：它把大部分问题拦在机器人时间之前。

### R1 — 真机 A/B 层（机器人在环，无微调）

客户只有三个：推理优化（验收）、Agent 框架（发布级）、RL 框架（等价性/安全）。协议要点：

- **交错 A/B**：reference/candidate 同 session、同物体、随机顺序交替跑；无法像仿真那样逐 episode 配对（真实世界非确定），用 session 内交错 + 固定布局集近似。
- **双盲打分**：录像 + ≥2 人独立事后判分，判分者不知模型身份。不花物理时间，纯赚。
- **失败分类**：力矩保护触发**单列**（控制器保护 ≠ policy 失败，否则会把"量化让动作变抖→触发保护"误读成"不会做任务"）。
- **首跑安全门**：candidate 首次上真机前必须通过 R0 动作分歧筛查（对 logged 观测的动作偏差异常大直接打回）；首个 session 以限速模式跑 sanity 不计分——限速会掩盖差异，计分轮恢复标准配置。量化/调度类改动可能产生暴力动作，此门不可省。
- **统计现实**（[[Real-robot evaluation]]）：n=10–30 时 CI ±15–30pp → **R1 只守大翻车，1–3pp 非劣性永远属于仿真**。唯一例外是抽屉自复位探针（§5），n=300+ 且二元 CI 仍约 ±8pp——灵敏度靠连续指标（位移曲线、CDF、win-ratio）继续下压。
- **"大效应检验 + 报告 CI"的准确含义**：与非劣性检验方向相反——非劣性是**主动证明**"差距 ≤ δ"（举证责任在 candidate，n 不够默认不通过）；R1 做的是差异显著性检验（Fisher 精确 / 交错置换），n=10–30 下只有 ~25pp 以上的效应能触发，**不显著 ≠ 非劣**，只是"没抓到大问题"。必须同时报告 Δ 的 95% CI，把"本实验未能排除多大的退化"摆在明面（例：n=20 观察到 −15pp，p≈0.5，CI ≈ [−40, +13]——与掉 40 个点的假设相容）。不在真机做大 δ 非劣性：δ=25pp 的 margin 无业务含义，通过了也不证明任何人关心的事。R1 的角色是**大效应否决权**，非劣性承诺由仿真层承担。

### R2 — 校准与里程碑层（低频）

- **sim-real 秩相关校准**（公共品，建议季度或引擎/渲染大版本前后）：选一组系统变体（不同量化档、引擎版本、渲染配置），仿真全跑 + 真机抽跑，算 Spearman 秩相关。相关性稳定 → 仿真验收有效力；相关性崩 → 停止信任对应仿真结论并排查。
- **3DGS real2sim-RL-real 环路**（渲染 + RL 框架 + 物理的联合里程碑）：真机资产 3DGS 扫描入仿真 → 仿真 RL 训练 → 回真机部署。判定"3DGS 减小 sim-to-real gap"建议三臂设计：**A** = 3DGS 孪生场景训练的 policy，**B** = 常规资产场景训练的 policy，**C** = reference π0.5（不经 RL），三者在同一套真机任务上交错评测。两个可分离的结论：①训练迁移（A 对 B 的真机成功率优势）；②评测保真（孪生场景内评测结论与真机结论的秩相关）——同一份扫描基础设施同时回答两个问题。

## 5. 任务集（按 R1 的客户需求张成）

组织原则：任务为方向需求服务；能力轴（[[Real-robot evaluation]] 的 8 轴）降为覆盖检查表，不再作为设计目标。

### 推理优化需要的结构

| 任务 | 为什么 | 备注 |
|---|---|---|
| **抽屉开合**（自复位探针） | 唯一能到 n=300+ 的高灵敏度回归探针；位移 cm 是无代理缺口的连续指标 | 专章见 §7；量化验收的主承载 |
| **叠 3–4 碗** | 长程误差累积——VLA 量化的特征失败模式（[[Xu et al. - QVLA Not All Channels Are Equal in Vision-Language-Action Models Quantization|QVLA]]），聚合成功率恰恰掩盖它 | 从 2 碗升级，2 碗容差太松 |
| **双臂交接果汁盒** | 时序/协调敏感——真实时序盲区的探针（对应仿真 Control 轴的真机 ground truth） | 保留现有资产 |
| 扰动条件（干扰物/光照/位置随机） | 挂在以上任务上，近零边际成本 | 条件不占任务位 |

### Agent 框架需要的结构

| 任务/条件 | 为什么 |
|---|---|
| **5 阶段长程串联**：开抽屉→取瓶→扶正→放筐→关抽屉 | 原子单独训过、组合没训过——组合泛化 + 长程；复用全部现有资产 |
| **扰动恢复**：执行中途人手移开目标物 10cm | 直击开环 chunk 预测软肋；零资产、每次多两秒；真实失败分布盲区的最便宜探针 |
| **记忆条件**：放置后布盖住，后续步骤需知道底下是什么 | 一块布的成本 |
| **指令 grounding 条件**：多瓶选一、空间关系、计数/逻辑 | 挂在抓瓶/扶瓶上，只改摆放和 prompt |

### 条件载体与链路原子（低 n，不承担回退检测）

| 任务 | 角色 | 说明 |
|---|---|---|
| **抓瓶子** | 指令/泛化条件的载体；reference 栈健康检查；串联链原子（取瓶） | 裸任务对精度回归低信息，价值全在挂载条件；数据复用已有 |
| **扶正瓶子** | 串联链原子（扶正）；非抓握动作最低成本覆盖；"把所有倒下的瓶子扶正"计数条件载体 | 零资产、近自复位；§2 新采清单已含 |

这两个任务必须在任务集内：**串联链的原子必须是单独训过的任务**——否则 5 阶段串联从"组合泛化测试"变质为"部分原子未见"；条件也需要已校准的载体。但它们不需要探针级样本量。

**果汁盒不单设单臂抓取任务**：按"任务 vs 条件"判据，只换物体是条件——果汁盒作为**物体变体**进入抓取任务的泛化条件组（采集时混入）。交接失败归因到"抓取 vs 协调"由交接任务的分阶段 progress 打分承担（阶段 1 即 arm1 抓取），不需要独立任务位。

### 明确砍掉的（新框架下没有客户）

- **轴 4 力调制**（抹布擦拭）、**轴 6 可变形**（折毛巾/装袋）：五个方向没有一个的验收需要它们，且仿真侧最难对齐——秩相关校准也用不上。
- **裸单步抓取作为 Agent 评测**：无条件加持的单步抓取对框架改动零信息；其评测价值全在挂载的指令/泛化条件上（见上表）。

### 新增约束：数字孪生友好性（为 §4 R2 的 3DGS 环路预留）

真机任务集就是 real2sim-RL-real 环路的终点读数，资产选择现在就要吃进可扫描性，否则将来要建平行任务集：

- **优先哑光、有纹理的刚体**；透明/高反光物体（玻璃瓶、亮面金属碗）是 3DGS 已知弱项——现有瓶/碗若为高光材质，补置哑光纹理款替代或并行。
- **铰接资产（抽屉）**：3DGS 只重建静态几何，关节需部件级重建 + 运动学标定，列入扫描计划（不阻塞 R1 使用，但孪生化前 R2 环路用不了它）。
- 任务初始布局须在重建场景中可复现（固定布局集本来就要做，孪生场景复用同一套）。

## 6. 打分与统计

- 验收：成功率非劣性（δ 有业务含义）；**time-to-success CDF** 作一等连续指标（成功率 = CDF 在 timeout 处取值，严格信息增益），属检测/筛选层——只需序关系 + 显著性，不设绝对阈值。
- **CDF 差异检验**（candidate vs reference）：
  - 前提：观察窗 [0, timeout] 完整——成功时间精确观测，未成功 episode 整窗无事件、贡献平坦曲线，**不需要 Kaplan–Meier**；但**不得只对成功样本检验**（条件在成功上 = 比较幸存者速度，两系统成功率不同时必偏），也不得把失败记成"用时 = timeout 的成功"。
  - 主检验：KS 型统计量 sup|F̂_A − F̂_B| 配**置换检验**取零分布（标准 KS 临界值对带质量缺额的子分布不适用）；交错随机化使 A/B 标签在 H0 下可交换——检验合法性由实验设计自带。
  - 效应量：**ΔAUC**（两条 CDF 下面积差，单位为秒，同时融合速度与成败变化）或中位完成时间差，bootstrap CI。
  - 配对增强（固定布局集）：**层级配对比较（win-ratio）**——同布局两系统各一次，先比成败、同成比用时、同败记平，sign/置换检验，小 n 下最稳。
- 诊断：SPARC/jerk **只在成功 rollout 上算**（"什么都不做最平滑"的方向性漏洞：畏缩/冻结型退化的平滑度反而更好，平滑走向错误物体也满分）。SPARC = 速度剖面的傅里叶谱弧长（越接近 0 越平滑，对噪声稳健，模型间比较优先用）；jerk = 位置三阶导（噪声敏感需滤波，但可对接本体规格书的加速度/jerk 上限——对接后升为硬约束层）。价值：量化/降步的退化先表现为轨迹抖动、后表现为成功率下降（Ω-QVLA 教训），且抖动是力矩保护触发的上游预测量；分段算（chunk 内 vs chunk 边界）可把退化归因到调度/时序 vs 数值误差。
- 分层详见 [[Real-robot evaluation]] 指标分层；仿真侧统计栈（非劣性检验、interim 控制、gatekeeping）见 [[Embodied simulation benchmark suite for systems optimization]] §4，真机 R1 因 n 小只做大效应检验 + 报告 CI。

## 7. 抽屉探针专章（推理优化验收的主承载）

`open → close` 天然回到初始状态，**可无人值守连续跑**——其他任务 n≈30，它可以 n=300+，是真机上唯一能检测 ~5pp 级回退的任务。

- **采购**：第一旋钮是把手（横杆→拉环→凹槽→无把手推拉），建议可换把手或 3D 打印面板；滑轨阻尼是第二旋钮（有阻尼档顺带覆盖力调制的最低需求）。
- **打分**：位移-时间曲线为连续指标（开：位移阈值+曲线；合：残余缝隙 mm）；可自动测量（滑轨标记+固定机位或深度相机）。
- **三个必踩的坑**：①柜体必须固定死（否则测的是"推柜子"且初始状态漂移毁掉所有配对统计）；②力矩保护单列为失败类别；③硬件漂移——滑轨跑几千次阻尼会变，**定期用脚本轨迹重测基线**，否则会把"抽屉变紧"误判成"模型退化"。
- 升级路径：v0 开合（探针）→ v1 开→取瓶→合（3 阶段）→ v2 五阶段串联（Agent 用）→ v3 一臂拉住+一臂取物（双臂闭链，若双臂时序需要第二个任务再启用）。

## 8. 立即可做（按性价比）

1. **搭 R0 管线**——logged 真实观测上的配对推理 harness。零机器人时间、最高杠杆，推理优化方向当天受益。
2. **重训 reference 到 π0.5**——确认已采数据格式，从 `pi05_base` 微调；这是共享栈的地基。
3. **human baseline + 难度校准到 40–70%**——校准完成前不开始正式评测。
4. **抽屉采购与固定**（含可换把手）；扫描友好性顺带核查现有瓶/碗材质。
5. **双盲打分流程 + 固定布局集**——不花物理时间。
6. 零成本条件两个：扶正瓶子、扰动恢复。

## 9. 待决问题

1. 单次评测的物理时间预算 → 决定 `任务 × 条件 × trial` 分配与抽屉探针的 n 上限。
2. R2 秩相关校准的变体集怎么选、多久跑一次、真机抽样多大。
3. 3DGS 铰接资产（抽屉）的部件级重建与关节标定方案。
4. 真机 RL 上线前的安全约束验证清单（力/速度限幅、工作空间围栏、e-stop 流程）。
5. 初始状态可复现性与打分细则的展开（[[Real-robot evaluation]] 子问题 2/3，所有交错统计建立在其上）。
