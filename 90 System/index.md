- [[Xu et al. - FAIL-Detect Uncertainty-Aware Runtime Failure Detection for Imitation Learning Policies]] — **"检测失败，但不需要失败数据"**（**Toyota Research Institute**，arXiv:2503.08558）。把问题重构为**序贯 OOD 检测**，两阶段：① 打分 `D_M(A_t,O_t)`，输入 = **最近 2 步观测 + 策略生成的未来动作**（刻意不喂增长历史，防过拟合）；② **conformal prediction 构造单侧时变 band**（从成功 rollout 算每时刻 μ_t 与带宽，**α 即误报率**；对比 STAC 的单一常数阈值）。**四类打分器**（学出密度 / 二阶分布 / 单类 / post-hoc）同框对比；最佳者 **logpZO**——用连续归一化流把观测**推进噪声空间**，分数 = **‖Z‖²**，**绕开直接算密度所需的高维散度积分**，仅 ~0.03–0.04 s/步。结论 **learned > post-hoc 且更快**（logpZO top-1 10/16）。真机 = **双臂 Franka 叠毛巾 / 擦洒漏**（OOD 由换色、加干扰物、人为拉扯制造）；**ID-only 校准即可覆盖 OOD**（冷启动无需预采 OOD）。⚠️ **与 Sentinel 的张力**：硬件上**没能实时跑 STAC**（每步 256 条采样，"slow to run on hardware in real-time"）⇒ "STAC 可端侧"需加限定
- [[Agia et al. - Sentinel Runtime Monitoring of Consistency and Progress for Generative Policies]] — **具身失败检测最完整的实证工作**（Agia/Pavone/Bohg 等，arXiv:2410.04640）。**失败分类学先于方法**：把失败分两类各配专用检测器——**erratic**（时间敏感但**视觉细微**）用 **STAC**：生成式策略 `k<h` 使 t 与 t+k 的 chunk **时间重叠**，比较两分布的**统计距离**，原理是"**分布内策略会同意自己刚才的预测，OOD 时自我矛盾**"（MMD+RBF，**策略无关、成本可忽略**，检出 **99%**）；**task-progression**（**视觉明显**但时间自洽）用**零样本 VLM**（GPT-4o/Claude 3.5/Gemini 1.5，输入=抽帧视频+任务+时限+已用时，三段式自问自答 prompt，**每 episode 仅查 2 次**、非阻塞）。并行 **>97%** 检出、**+18%** vs 单用任一；**真机 Push Chair 95%**。**⚠️ 两处证伪**：① 朴素"看采样方差"是**被 STAC 击败的 baseline**；② "必须采失败样本"——STAC 校准**只需成功 rollout**（同 FAIL-Detect *without failure data*）。**核心结论**：分层依据是**成本 × 紧迫性 × 信号模态**三维，第三维（两类失败在**不同表征空间**才可见）才是"必须有两个检测器"的根本原因
- [[Seligmann et al. - VLA-FAIL Efficient Task Failure Detection for Finetuned Vision-Language-Action Models]] — **把失败检测的成本压到近零，并首次在大 VLA 上验证**（FZI + KIT，arXiv:2606.21386）。**LLMD**（最后一层逐 token 马氏距离，靠"固定先验噪声 `t=0`"绕开 flow matching 噪声污染）补上本库缺的**表征侧信号位**，擅长抓最易漏的**进展停滞**；**ACC** 是 **STAC 的单样本速度归一化估计**（1 vs 256 采样）却在真机上几乎全面胜过它。**逻辑 OR + 恒定 CP 阈值**；新指标 **AUCPDT**。⚠️ LLMD 需访问微调数据
- [[Romer et al. - FIPER Failure Prediction at Runtime for Generative Robot Policies]] — **"benign OOD ≠ 失败"的量化出处**（TUM，NeurIPS 2025，arXiv:2510.09459）。**RND-OE**（复用冻结策略自身观测编码器，10 条成功 rollout 可训，不需策略训练数据）+ **ACE**（论证 IL 多模态是离散的 ⇒ 该测熵不是方差）；**逻辑 AND** 且证明合取仍守同一误报上界；**时变 CP 阈值**。⚠️ AND 的代价自家表格已量化（更准但更慢）；准确率 0.78 作者自陈对装配线仍不够；仅单任务小策略
- [[Feng et al. - DVAC Denoising-Variance Adaptive Chunking for Flow-Based Robot Policies]] — **⚠️ 不是失败检测**：同族信号当**变速箱而非刹车**（深圳河套 + 港中深，arXiv:2606.03847）。发现**去噪尾部方差 ≈ 免费的任务阶段检测器**（移动低/接触高，`r<−0.27`），据此**执行低方差前缀、在高方差动作提交前重规划**。π₀.₅ 上 LIBERO **0.948→0.980 且重规划 −43%**，training-free。⚠️ 作者自陈是 empirical proxy 非校准不确定性；仅流/扩散动作头
- [[NVIDIA - Isaac Lab-Arena Scalable Robot Policy Evaluation in Simulation]] — **把"造 benchmark + 跑评测"本身做成开源框架**（NVIDIA Technical Blog 2026-01-05，**与 Lightwheel 共同开发**，**pre-alpha**）。痛点原话："大规模评测搭建**又繁又手工**，自建基础设施开销高，而任务库**复杂度与多样性不足**"。核心：**Object / Scene / Embodiment / Task 四类独立积木即时编译成环境**（替代整块写死的任务描述）+ **Affordance 系统**（`Openable`/`Pressable`）标准化交互**让一个任务跨物体复用**；换物体/本体/场景**不改管线**；**策略无关**。性能（Lightwheel 实测）：**GR00T N1.5 × 10 个 RoboCasa 任务 × 每任务 4096 同构变体 × 8×6000D GPU** → **并行 0.76h vs 串行 34.9h**。生态：Lightwheel 开源 **250+ 任务**（RoboCasa/LIBERO 套件）+ 工业基准 RoboFinals、**LeRobot Environment Hub**（可评 GR00T N/π0/SmolVLA）、RoboTwin 2.0 扩展、GEAR Lab。路线图**沿本库 L0–L3 评估栈往上**（NuRec real-to-sim = L2；**Cosmos 神经仿真 = L3**）。**⚠️ 三条限定**：pre-alpha"early framework skeleton"；**仅同构并行**；**40× 是 Arena 并行 vs Arena 串行的内部对照，非 vs MuJoCo**；且**全文无 sim-to-real 相关性数字** ⇒ **它是吞吐工具不是保真度工具，只解决"可比+快"、没碰"可信"**。意义：**"评估算力成为一等预算项"最强的一类证据——卖算力的人用产品投票**
- [[FAR - Failure-Aware Retry for Test-Time Recovery and Continual Policy Improvement]] — **恢复四格里唯一"改策略本身"的那格**（arXiv:2607.01111）。诊断很准：失败状态**很少被离线演示覆盖、对策略是 OOD**，故**朴素重试只重复同样的错误**；且现有恢复法**多依赖人工介入**。四部件：① **IQL** 同训 `Q_φ`+`V_ψ`，用**时序价值差定位失败诱因动作**（**替掉"人来标哪步错了"**）② **FCPA** 用失败经验构偏好数据（失败动作为负例 + 替代正例），**测试时更新策略** ③ **轻量动作扰动**（因 FCPA 受限于离线策略 support，扰动才能在 OOD 状态扩 support；仿真中高斯扰动足够）④ **成功恢复轨迹进 replay buffer** → 持续改进，且**价值估计一并变好**。结果：仿真 **+17.6%** / 真机 **+11.7%**（vs 标准 diffusion policy），**recovery without environment resets**，reset 与 timestep **两种预算下数据效率均提升**；3 sim benchmark/9 任务（50ep，≤5 次尝试，3 seeds）+ **7-DoF xArm** 3 任务。**⇒ 本库第一个闭合"恢复→数据→改进"环的工作**，把**运行时通道**与**演进通道**接起来；且给 [[Robot data engine]] 的"质量信号提取"一个自主解法（双组分杠杆的人类支点**存在可自主化的子类**）。与 [[Physical Intelligence - pi0.6 a VLA That Learns From Experience|π*₀.6 Recap]] 同思想不同时间尺度（离线车队级 vs 在线单集内）。**⚠️ 未用公开 benchmark；在线更新的稳定性风险未系统讨论；整条链依赖价值函数在 OOD 状态的可靠性**
